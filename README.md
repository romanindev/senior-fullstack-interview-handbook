# Senior Full Stack Engineer Interview Handbook

An open-source, vendor-neutral handbook for developers preparing for Senior Full Stack Engineer interviews.

The project focuses on practical engineering knowledge, interview-ready explanations, and real-world decision-making across React, TypeScript, Node.js, architecture, system design, CI/CD, testing, performance, security, and leadership.

## Who this handbook is for

This handbook is useful for:

- Senior Frontend Engineers moving toward Full Stack or Lead roles
- Full Stack Engineers preparing for product-company interviews
- Lead Engineers who want to refresh architecture and system design fundamentals
- Developers who want practical, structured interview preparation material
- Contributors who want to help build a public technical learning resource

## What this project is not

This project is not:

- A company-specific interview guide
- A personal career handbook
- A collection of shallow interview answers
- A LeetCode-only preparation repository
- A generated Q&A dump

The goal is to build a long-term, public documentation project with a high quality bar.

## Main topics

- Modern React
- TypeScript
- Node.js
- Software Architecture
- System Design
- CI/CD and DevOps
- Testing
- Performance and Security
- Leadership and Behavioral Interviews
- Company Interview Notes
