# Security Policy

## Reporting security issues

If you find a security issue related to this repository, please do not open a public issue with sensitive details.

Instead, contact the maintainer privately through GitHub.

## Scope

This repository is primarily a documentation project.

Potential security issues may include:

- Exposed private information
- Malicious links
- Unsafe scripts
- Compromised workflow files
- Suspicious contributed content

## Public content policy

Do not contribute:

- Secrets
- Tokens
- Private keys
- Internal company documents
- Confidential interview materials
- Private personal data
