# AGENTS

This file provides general instructions for AI agents working in this repository.

## Repository mission

Build and maintain a high-quality public handbook for Senior Full Stack Engineer interview preparation.

## Required behavior

AI agents must:

- Read `README.md`, `ROADMAP.md`, and `PROGRESS.md` before making changes
- Follow `CONTRIBUTING.md`
- Follow `STYLE_GUIDE.md`
- Avoid duplicating existing content
- Keep content vendor-neutral
- Keep content non-personalized
- Use English
- Use Markdown
- Update `PROGRESS.md` after meaningful work

## Content standards

Content must be:

- Practical
- Technically accurate
- Senior-level
- Structured
- Reviewable
- Useful without private context

## Forbidden content

Do not add:

- Private interview questions
- Confidential company information
- Candidate-specific content
- Personal career details
- Unsupported claims
- Low-quality generated text

## Preferred workflow

1. Inspect existing docs.
2. Choose the correct folder.
3. Add or update one focused file.
4. Add internal links where useful.
5. Update section README if needed.
6. Update `PROGRESS.md`.
7. Suggest follow-up work.
