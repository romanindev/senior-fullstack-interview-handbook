# Roadmap

This roadmap describes the planned structure and milestones for the handbook.

The goal is to build the project incrementally, keeping each section reviewable, maintain, and useful on its own.

## Status legend

- Not started
- In progress
- Draft complete
- Reviewed
- Ready for release
